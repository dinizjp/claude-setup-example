# Projetos

Uma pasta por projeto. Projeto não precisa ser programação: pode ser o controle das suas finanças, um estudo, a organização de um cliente ou um conjunto de textos.

Cada pasta tem:

- um `README.md`: um texto curto que diz o que o projeto faz, como usar e onde ficam os dados. A IA lê esse arquivo antes de mexer no projeto;
- um projeto com o mesmo nome no seu gestor de tarefas;
- a skill do projeto, se houver, em `skill/SKILL.md`.

## Git e GitHub (opcional)

O **Git** guarda o histórico de cada mudança nos arquivos: o que mudou, quando e por quê. Se a IA estragar alguma coisa, você volta para a versão de antes. Uma pasta com esse histórico se chama **repositório**.

O **GitHub** guarda uma cópia do repositório na internet. Serve de backup e deixa você compartilhar o projeto, como este aqui.

Você não precisa usar nenhum dos dois para começar. Mas, se a IA vai mexer nos seus arquivos, vale pedir para ela criar um repositório em cada projeto: o histórico é a sua rede de segurança.

## Dicas

- Comece pequeno. Um script que resolve um problema seu já é um projeto. Ele ganha uma skill quando você percebe que pede a mesma coisa para a IA toda semana.
- Projeto que morreu: decida se vai para um backup ou para o lixo. Não deixe pasta parada aqui.
