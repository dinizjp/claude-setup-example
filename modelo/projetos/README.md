# Projetos

Uma pasta por projeto. Cada uma tem:

- um repositório git próprio (a pasta `projetos/` fica fora do git da raiz);
- um projeto próprio no gestor de tarefas, com o mesmo nome;
- um `README.md` que diz o que o projeto faz, como rodar e onde ficam os dados;
- a skill do projeto, se houver, em `skill/SKILL.md`, com link simbólico em `~/.claude/skills/<nome>`.

Comece pequeno: um script que resolve um problema seu já é um projeto. Ele ganha skill quando você percebe que pede a mesma coisa ao Claude toda semana.

Projeto que morreu: decidir se vai para um backup ou para o lixo. Não deixar pasta parada aqui.
